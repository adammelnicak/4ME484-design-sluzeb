# Komunikace a podpora

## Kde hledat informace

- Tento GitHub repozitář obsahuje zadání, pravidla, harmonogram, hodnoticí kritéria a zveřejněné materiály.
- Microsoft Teams slouží pro dotazy, konzultace, oznámení změn a domluvu s
vyučujícím.
- InSIS nebo jiné prostředí VŠE použijeme pouze pro zaznamenání finálního hodnocení a případně výpis termínů zkoušky.

Pokud si dva dokumenty odporují, upozorněte na to vyučujícího. Do vyjasnění
platí novější informace v tomto repozitáři a oznámení v Teams.

## Kdy napsat přímo vyučujícímu

Napište přímo Adamovi, pokud:

- si podklady odporují nebo potřebné pravidlo chybí;
- projekt zahrnuje citlivé údaje nebo zranitelné účastníky;
- tým nemá přístup k lidem, službě nebo podkladům potřebným pro pokračování;
- konflikt v týmu brání další práci nebo společné dohodě;
- potřebujete probrat osobní situaci neveřejně.

Do veřejného kanálu ani GitHub issues nepatří osobní údaje, zdravotní
informace, konflikty v týmu ani neveřejné informace partnerů.
